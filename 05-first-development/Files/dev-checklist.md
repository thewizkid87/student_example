# Development Checklist

Use this checklist during the lesson and during the MVP homework.

For the full home project, use [project.md](../Homework/project.md).

## One-Task Development Loop

1. Open `project-hld.md`.
2. Open `<idea>-tasks-final.md`.
3. Choose one task.
4. Ask Codex to implement only that task with [implementation-loop-prompt.md](./implementation-loop-prompt.md).
5. Run the app locally.
6. Inspect the result in the browser or terminal.
7. Debug exact errors with [debugging-prompt.md](./debugging-prompt.md).
8. Commit the completed task.
9. Move to the next task.

## What Counts As Done For One Task

- The app still runs.
- The feature or fix can be seen or tested.
- The change matches `project-hld.md`.
- The change belongs to one task from `<idea>-tasks-final.md`.
- Any browser storage behavior can be verified.
- The change has a meaningful commit.

## Stop And Ask Before

- Changing the selected stack.
- Adding a backend.
- Adding a database.
- Replacing the planned browser storage approach.
- Combining several MVP features into one large change.
- Deleting working code you do not understand.
