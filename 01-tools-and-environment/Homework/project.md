# Week 1 Home Project: About Me

## What

Create a personal `about-me.md` file and commit it to GitHub.

Your course copy is public. Use a name you are comfortable publishing. Birth month and year are optional. Leave out your address, phone number, email address, exact birth date, precise location, passwords, and tokens.

Your file should include:

- who you are
- why you joined the course
- one thing you want to build

## Why

This task gives you your first complete course workflow: use Codex for drafting, edit a markdown file, commit the file with Git, and push it to GitHub.

This is the same pattern you will repeat on larger tasks later: understand the request, create the file, check the result, commit the work, and verify it online.

## How

Use Codex to help you draft the first version, but keep control of the final file.

Start with [../Files/about-me-prompt.md](../Files/about-me-prompt.md). If you want more personalization after the first draft, use [../Files/about-me-extended.md](../Files/about-me-extended.md). If you need Codex command or prompt examples, use [../Files/codex-cheatsheet.md](../Files/codex-cheatsheet.md).

Use [../Files/markdown-cheatsheet.md](../Files/markdown-cheatsheet.md) when you want formatting help and [../Files/bash-cheatsheet.md](../Files/bash-cheatsheet.md) when you need terminal reminders.

## Acceptance Criteria

- `about-me.md` exists in your repository
- the file is written in markdown
- the file includes who you are, why you joined the course, and one thing you want to build
- the file sounds like you, not like a generic profile
- the file has been reviewed for private information before the public push
- the file is committed with Git
- the commit is pushed to GitHub
- you can open the repository on GitHub and see `about-me.md`

## Submission

Push your completed `about-me.md` file to GitHub.

The task is submitted when:

- the file is visible in your GitHub repository
- the repository has a commit that includes `about-me.md`
- you can show the file from GitHub during the next class
