# Markdown Cheat Sheet

Use this file in preview mode to see what Markdown looks like when it renders.

## Headings

# H1 This is a BIG header

## H2 Used for sub subjects

### H3 Used for smaller sections

#### H4 Used for details inside a section

## Text Styles

**This text is bold**

*This text is italic*

`This is inline code`

## Lists

- First bullet
- Second bullet
- Third bullet

1. First numbered item
2. Second numbered item
3. Third numbered item

## Links

[OpenAI](https://openai.com)

[GitHub](https://github.com)

## Quotes

> This is a blockquote.
> Use it for short quoted text or important callouts.

## Code Blocks

```bash
git status
git add .
git commit -m "first commit"
```

```text
This is plain text inside a code block.
```

## When To Use What

- Use headings to split the page into clear sections
- Use bold for important words
- Use italics for emphasis
- Use lists when you have multiple items
- Use links instead of writing out long URLs
- Use code blocks for commands, examples, and raw text
