# Repo Tour Prompt

Paste this into Codex:

```text
You are helping me understand this course repository.

Look at the folders and files in this repo and help me create a simple markdown file called repo-tour.md.

Start by explaining what you see in the repository.
Then ask me if I want the explanation to be shorter, clearer, or more beginner-friendly.

The final repo-tour.md should explain:
- what the Lesson folder is for
- what the Homework folder is for
- what the Enrichment folder is for
- what the Files folder is for
- what I should open first when starting a week

Keep it short and practical.
Do not make it sound formal.
```

## How To Use It

- Start Codex from the course repository folder
- Paste this prompt into Codex
- Use the response to create `repo-tour.md`
- Preview `repo-tour.md` in VS Code
- Commit and push `repo-tour.md` before starting the homework
