# About Me Extended Ideas

Use these follow-up ideas after the first draft is generated.

Keep the public file free of address, phone, email, exact birth date, precise location, credentials, and other sensitive details. Name and optional birth month/year are fine.

## Follow-Up Ideas

- Ask me to make the tone more casual or more professional
- Ask me which hobby or interest should be highlighted more
- Ask me for one concrete example that proves I care about the topic
- Ask me what kind of project I would actually enjoy building
- Ask me what I want the course to help me get better at
- Ask me to shorten the file if it feels too long
- Ask me to make the introduction sound more like a real person and less like a form
- To start from scratch, return to [about-me-prompt.md](about-me-prompt.md)

## Useful Follow-Up Prompts

```text
Can you make this sound more like me?
```

```text
Can you make the hobby section more specific?
```

```text
Can you add one sentence about why this course matters to me?
```

```text
Can you make this shorter without losing the personal details?
```

```text
Can you give me one stronger opening line?
```
