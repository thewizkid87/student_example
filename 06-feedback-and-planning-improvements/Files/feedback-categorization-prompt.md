# Feedback Categorization Prompt

Use this prompt after you have raw feedback notes from an MVP demo.

```text
Read my raw feedback notes.
If available, also read project-hld.md so you understand the project goal and intended MVP.

Your job is to organize the feedback before we decide what to build.

Do not turn every request into a task.
Do not assume every opinion is correct.
Ask questions if the feedback is too vague to categorize.

Group the feedback into:

- Observations
- Bugs
- User confusion
- Feature requests
- Polish or usability improvements
- Later ideas
- Opinions that need more evidence

For each item, include:

- the original feedback or observation
- the category
- the likely user problem
- whether it affects the core MVP flow
- any question I should answer before deciding

Then identify repeated patterns across the feedback.
```
