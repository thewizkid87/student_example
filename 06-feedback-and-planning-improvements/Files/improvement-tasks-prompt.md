# Improvement Tasks Prompt

Use this prompt after `feedback-plan.md` exists.

```text
Read feedback-plan.md.
Also read project-hld.md and my final MVP task list if they are available.

Your job is to create or revise <idea>-improvement-tasks.md.

Create small implementation tasks for the next development session.
Each task should include:

- Task title
- Feedback source or decision
- What should change
- Why it matters
- Files or areas likely involved, if known
- Verification step
- Done condition
- Priority: required now or wait

Keep tasks small enough to implement and test one at a time.
Mark large ideas as wait unless they are required for the core MVP.
Ask questions before creating tasks if the feedback plan is unclear.
```
