# Project Idea Examples

Pick one idea and still use [summary-stage-prompt.md](./summary-stage-prompt.md). Do not skip the question stage.

## Ideas

- Personal task tracker - A small app for tracking personal tasks and completion status.
- Study timer - A timer that helps someone focus during study blocks.
- Budget splitter - A tool for splitting shared expenses between people.
- Chore rotation helper - A tool that assigns recurring chores to people.
- Reading list manager - A way to track books or articles someone wants to read.
- Workout logger - A simple log for exercises, sets, reps, and notes.
