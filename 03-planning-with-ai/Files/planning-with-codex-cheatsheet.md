# Planning With Codex Cheatsheet

Use this cheatsheet when you need short prompts during Week 3 planning.

## Start A Planning Stage

Ask Codex:

```text
Read 03-planning-with-ai/Files/summary-stage-prompt.md and guide me through it.
```

Ask Codex:

```text
Read my idea summary file and 03-planning-with-ai/Files/mvp-stage-prompt.md.
Guide me through the MVP stage.
```

Ask Codex:

```text
Read my idea summary file, my MVP file, and 03-planning-with-ai/Files/tasks-stage-prompt.md.
Guide me through the task stage.
```

## Ask For Missing Requirements

Ask Codex:

```text
Read this planning file.
What important requirements are missing?
Ask me questions instead of guessing.
```

## Improve The User

Ask Codex:

```text
Read this summary.
Is the target user specific enough to guide feature decisions?
If not, ask me follow-up questions.
```

## Improve The Problem

Ask Codex:

```text
Read this summary.
Does the problem explain a real user need?
If it only describes a feature, suggest a stronger problem statement.
```

## Check MVP Scope

Ask Codex:

```text
Read this MVP file.
Which features are not required for the first useful version?
Move them to version 2 or version 3.
```

## Evaluate Stack Choice

Ask Codex:

```text
Read this summary and MVP.
Recommend a language or stack for the first version.
Explain the recommendation based on project type, beginner-friendliness, and local setup.
```

## Create An App Skeleton First Task

Ask Codex:

```text
Read this MVP file.
Create development tasks.
The first task must create the app skeleton for the selected language or stack.
```

## Check Whether Ideas Are Different

Ask Codex:

```text
Read idea-1-summary.md, idea-2-summary.md, and idea-3-summary.md.
Are these meaningfully different project ideas?
If two are too similar, explain why and suggest how to separate them.
```
