# Release Notes Cheat Sheet

Release notes explain what changed in the current version.

Use [release-notes-prompt.md](./release-notes-prompt.md) when you want Codex to create or revise them.

## Useful Sections

```md
# Release Notes

## Changed

- Improved task editing flow based on feedback.

## Fixed

- Fixed saved data not loading after refresh.

## Improved

- Added clearer empty-state text.

## Known Limitations

- Data is stored in the browser only.

## Future Work

- Add account syncing in a later version.
```

## Changed

Use `Changed` for behavior that is different than before.

Example:

```md
- Changed the add-item flow to show validation before saving.
```

## Fixed

Use `Fixed` for bugs.

Example:

```md
- Fixed a bug where blank items could be saved.
```

## Improved

Use `Improved` for polish and clarity.

Example:

```md
- Improved button labels to make the main action clearer.
```

## Known Limitations

Use `Known Limitations` for honest gaps.

Example:

```md
- The app stores data only in this browser.
```

## Future Work

Use `Future Work` for ideas that should not be built now.

Example:

```md
- Add shared accounts in a future version.
```
