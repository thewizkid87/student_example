# Netlify Account Setup

Use this file to create the free Netlify account you will need for deployment.

For the Week 7 homework task, see [project.md](../Homework/project.md).

## What You Are Creating

Netlify is a hosting platform that can deploy a web app from a GitHub repository.

In this step, you only create the account. Do not deploy the project yet.

## Before You Start

You need:

- a GitHub account
- access to the GitHub repository for your project
- a browser

## Step 1: Open Netlify

Open this page in your browser:

[https://app.netlify.com/signup](https://app.netlify.com/signup)

You should see the Netlify sign-up page.

Screenshot: [netlify-signup.png](./screenshots/netlify-signup.png)

## Step 2: Choose GitHub Sign-Up

Click:

```text
Sign up with GitHub
```

Use GitHub because your project already lives in GitHub and Week 8 deployment will connect Netlify to your repository.

## Step 3: Authorize Netlify In GitHub

GitHub may ask you to sign in.

If GitHub asks for authorization:

1. Read the permissions screen.
2. Confirm that the app is Netlify.
3. Click the authorization button.

You should return to Netlify after GitHub authorization finishes.

## Step 4: Confirm You Are In Netlify

After sign-up, you should see the Netlify dashboard or an onboarding screen.

You are done when you can see that you are signed in to Netlify.

Do not import or deploy the project yet. That happens in Week 8.

## If Netlify Asks About A Team Or Plan

Choose the free option.

Do not enter payment information for this course.

If Netlify asks what you want to do first, choose an option that lets you continue to the dashboard. Do not start a deployment yet.

## Verification

Before you finish homework, verify:

- you can go to [https://app.netlify.com/](https://app.netlify.com/)
- you are signed in
- you can see the Netlify dashboard or account home page
- you did not deploy the project yet
