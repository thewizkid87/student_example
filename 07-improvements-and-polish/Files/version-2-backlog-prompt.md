# Version 2 Backlog Prompt

Use this optional prompt when you want to preserve future ideas without expanding the current release.

Copy and paste this prompt into Codex:

```text
Read `feedback-plan.md`, `release-notes.md`, and `<idea>-improvement-tasks.md` if they exist.

Create a Version 2 backlog.

Include:
- deferred feedback
- future ideas
- tasks that were too large for the current release
- known limitations that could become future work
- a short reason for each backlog item

Follow these rules:
- Keep Version 2 separate from current required work.
- Do not add these items to the current release plan.
- Group similar ideas together.
- Mark each item as small, medium, or large.
- Ask me questions if an item is unclear.
```
