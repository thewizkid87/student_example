# Polish Checklist

Use this checklist before marking the project ready for Week 8 deployment and presentation.

For the homework task, use [project.md](../Homework/project.md).

## App Behavior

- The app starts locally.
- The core flow still works.
- Selected improvements from `<idea>-improvement-tasks.md` are implemented.
- Completed tasks were tested or verified.
- Browser storage still works after refresh if the app saves data.
- No new backend or database was added unless already approved.

## User Experience

- Confusing labels or instructions are clarified.
- Empty states are handled.
- Input validation gives useful feedback.
- Error messages help the user recover.
- Buttons and links use clear wording.
- The app does not show obvious unfinished placeholder text.

## Project Record

- `<idea>-improvement-tasks.md` marks only verified tasks as complete.
- `README.md` explains what the app does.
- `README.md` includes local run instructions.
- `release-notes.md` explains what changed.
- Future ideas are separated from completed work.

## Stop And Defer

Defer work when:

- it adds a new major feature
- it needs a backend or database that was not already planned
- it risks breaking the app before Week 8
- it does not directly support the selected feedback decisions
