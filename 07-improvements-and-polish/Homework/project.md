# Week 7 Home Project: Finish Improvements And Release Notes

## What

Finish selected improvements from your Week 6 improvement task list.

By the end of this homework, your app should be improved, verified, documented, and ready for Week 8 deployment and presentation.

Create or update:

- `README.md`
- `release-notes.md`
- `<idea>-improvement-tasks.md`

Also create a free Netlify account for Week 8 deployment. Do not deploy yet.

## Why

Feedback only matters if it turns into better software. Week 7 is where you improve the MVP, document what changed, and decide what will wait for a future version.

A smaller stable app is better than a larger unfinished app. This homework prepares the project for deployment and final presentation without starting a new project.

## How

Work from:

- `feedback-plan.md`
- `<idea>-improvement-tasks.md`
- `project-hld.md`
- the running app
- [polish-checklist.md](../Files/polish-checklist.md)

Use [improvement-loop-prompt.md](../Files/improvement-loop-prompt.md) to implement one improvement at a time. Use [polish-review-prompt.md](../Files/polish-review-prompt.md) if you need Codex to look for small polish issues.

After each selected change:

- run the app
- verify the behavior
- update `<idea>-improvement-tasks.md` only after verification
- commit the change

Use [readme-update-prompt.md](../Files/readme-update-prompt.md) to create or revise `README.md`. Copy local run instructions from app comments, package files, or the command you used during development.

Use [release-notes-prompt.md](../Files/release-notes-prompt.md) to create or revise `release-notes.md`.

Do not add deployment instructions unless the project is already deployed. Deployment belongs in Week 8.

Use [netlify-account-setup.md](../Files/netlify-account-setup.md) to create a free Netlify account with GitHub sign-in. Stop after you can see the Netlify dashboard.

## Acceptance Criteria

- Selected improvements from `<idea>-improvement-tasks.md` are implemented.
- Every completed improvement was tested or verified.
- `<idea>-improvement-tasks.md` shows completed status only for verified work.
- `README.md` exists and is updated.
- `release-notes.md` exists and is updated.
- The app still runs locally.
- A free Netlify account was created with GitHub sign-in.
- You can access the Netlify dashboard.
- The project was not deployed yet.
- Changes are committed in meaningful commits.
- The latest work is pushed to GitHub.

Total: 240 minutes.

Commit and push:

- improved app source files

- `README.md`
- `release-notes.md`

Your pushed repository should show an improved app that is ready for Week 8 deployment and presentation.
