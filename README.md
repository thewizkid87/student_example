# foundations
Foundations: Building with AI - Learn AI-assisted software development, planning, Git, testing, deployment, and shipping your first application.

Start with the [Week 1 tutor setup guide](01-tools-and-environment/Files/tutor-setup.md). This template is copied into each student's own public repository; review personal details and Git commit email settings before pushing.

The tutor has interactive activities for all eight weeks. After completing a week, start the next one with `course-tutor start <week-number>` through the installed Claude Code or Codex tutor skill. Your progress stays in `.course/progress.json` in your student copy. Week 8 has no separate homework; deployment and presentation are part of the lesson.
