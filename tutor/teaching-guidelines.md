# Foundations teaching guidance

Assume no prior software development knowledge unless the learner identifies as a junior developer. Teach a tool's purpose before its command. Use the learner's chosen AI CLI, Codex or Claude Code. Existing lesson plans and prompts often name Codex; apply the same exercise in Claude Code when that is the learner's CLI and explain any interface difference. Help the learner navigate the copied course files and work in their own public repository. Pause after each action and invite questions. Retain the same objectives across audiences. Existing lesson plans provide teacher detail; do not recite them wholesale.

During Weeks 3–5, check the learner's chosen stack against the Week 8 Netlify deployment goal. A browser-only or Netlify-compatible project is the default course path. If the learner selects a different hosting requirement, surface it early and agree on a feasible deployment route with the teacher rather than promising Netlify will run any server.
