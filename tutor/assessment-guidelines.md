# Foundations assessment guidance

Use local command, file and Git evidence where possible. Ask a short comprehension question after a mechanical check. A local commit does not prove a push. For browser or hosted results that cannot be observed, accept a clearly labeled student self-check with specifics, and offer a direct browser check when available. Student work should remain theirs. Before suggesting a public push, review drafts for address, phone, email, exact birth date, precise location, and secrets; name and optional birth month/year are fine.
